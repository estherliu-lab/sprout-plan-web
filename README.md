## 不用把一天排得满满的

有些早晨精神很好，有些下午只想安静抱一抱。小芽计划会跟着孩子的年龄和家长当天的状态，准备刚刚好的亲子灵感。五分钟也可以开始，临时想休息、做家务或出门走走，也都是一天里自然的学习。

## 学习就藏在真实生活里

一起看天气、挑衣服、准备早餐、整理玩具、收拾出门的小背包……这些每天都会发生的小事，本来就在帮助孩子练习表达、观察、分类、动作与独立生活。小芽计划把它们轻轻串起来，让家长不用额外扮演“老师”。

## 想做英语启蒙，也不必担心不会说

英语活动会把适合亲子游戏的词和短句准备好，并附上中文意思、开场方式和朗读按钮。家长不需要讲很长的英语，只要在游戏里自然重复一两句，孩子就能在动作、故事和笑声中慢慢熟悉。

## 看得见成长，也允许慢慢来

今天说的一句话、完成的一次小尝试、一起观察到的一片叶子，都可以留在成长花园里。这里没有分数、排名和催促打卡，只有属于你们家的节奏，以及一点一点长出来的能力。

## 小芽还会继续长大

**活动项目不断更新中。** 新的亲子游戏、生活流程课程和英语启蒙灵感会陆续加入，让每一次打开都可能遇见一点新鲜的小惊喜。

> 孩子的小名、年龄、头像、计划与成长记录只保存在当前设备上。

### 放到手机桌面

安卓手机可以使用自带浏览器或平时常用的浏览器，从菜单中选择“添加到桌面”“添加到主屏幕”“安装应用”或“创建快捷方式”。iPhone / iPad 可以在 Safari 的分享菜单中选择“添加到主屏幕”。

也可以在微信中打开小芽计划，点击右上角“…”并选择“收藏”，以后从微信“我 → 收藏”中进入。
